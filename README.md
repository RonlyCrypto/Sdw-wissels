# SDW O8-3 Wissels

Wisselschema voor SDW O8-3: 4 × 10 minuten, wissel elke 5 minuten, keeper per kwart, wissels afvinken en een wedstrijdklok.

- **Website:** https://ronlycrypto.github.io/sdw-wissels/ (op Android: menu ⋮ → *Toevoegen aan startscherm*)
- **Android-app:** download `SDW-Wissels.apk` bij [Releases](https://github.com/RonlyCrypto/sdw-wissels/releases/latest)
- **Meekijken:** bij *Team* staat een link met teamcode. Wie die opent, ziet dezelfde indeling, klok en vinkjes.

De gedeelde stand wordt opgeslagen in Supabase (project `sdw-wissels`).
